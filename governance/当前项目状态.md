### 7.5 生命周期模型 + 标签（GPT #440 敲定）

> **生命周期（描述现在怎么办）**：legacy_candidate 不再是生命周期，降为标签

```
discovery → confirmed → deprecated → archived → removed
```

| 生命周期 | 含义 |
|---|---|
| discovery | 只是发现：存在但不知是否运行 |
| confirmed | 事实确认：当前生产路径使用 |
| deprecated | 确认不用，但仍可能被参考 |
| archived | 不再维护，但保留历史 |
| removed | 删除 |

> **标签（描述它是什么）**：legacy_candidate / poc / replaced

**铁律**：archived 不代表可以删除；代码资产归档前必须确认无依赖（GPT #434）。

**当前 deprecated 清单**

| 资产 | 标签 | 依据 | 待办 |
|---|---|---|---|
