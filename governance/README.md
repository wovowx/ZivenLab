> **推进唯一依据（铁律 · 柳柳 2026-09-04 确认）**：
> 任何规则、知识、状态，若没有进入 Runtime 可加载/验证的生效路径，即视为不存在。
> 本目录集中存放系统级治理规范、目标架构、跨仓库现状摘要、项目状态与行动计划；历史讨论草稿留在 `common-ground/`。先从本页入口或 `governance/真相源导航表.md` 找到对应权威文件，不要仅凭文件名或旧路线段落判断当前状态。**本目录不是所有事实的唯一存储库**：组件实现以对应仓库源码/注册与测试证据为准，数据库实际结构以实时 Schema 为准，身份根与当前工作检查点以云端记忆中的指定对象为准。

## 📍 权威范围与生效状态

- **系统治理层**：本目录的治理规范、目标架构、跨仓库现状摘要与行动路线。
- **组件实现层**：对应组件仓库的源码、配置、工具注册及可复核测试；本目录只汇总，不取代组件证据。
- **数据层**：实时数据库 Schema 说明当前结构；治理文档记录设计意图、约束与变更历史。
- **身份/运行状态层**：云端 `🧬/我是谁` 是身份根，`⚙️/当前工作检查点` 是唯一权威当前工作状态；本目录的驾驶舱提供项目治理视图，不维护平行工作检查点。
- **生效证据**：文档已定义、运行时已接入、行为已验证是三种不同状态，必须分别记录。

## 🚩 引用规范

- 权威文档互相引用**写路径**（如 `governance/roadmap.md`），不写「85号」这种名字——文件名会变，路径才是导航。
- **复制/移动文件一律用 `github_copy`**（内容不经 Agent 上下文，MCP 服务端内部搬运），绝不手写整份大文件重推（费 token + 转义/截断风险）。需要改内容：先 copy 再对目标小幅 edit/push。
- 版本规则：本仓为文档仓，用知识快照 `docs-YYYY.MM(.N)`；代码仓（mcp-memory）用 `vX.Y.Z`。详见 `governance/当前项目状态.md` 第 10 章。
