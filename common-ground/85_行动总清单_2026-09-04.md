### P0-2 唤醒桥投递链路修复
- 状态：🔵 进行中（根因已定位：事件生命周期不闭环）
- Owner：Ziven；Reviewer：GPT
- **根因（#390/#391 确认）**：不是轮询，是 claim 后没有配套 ack/watchdog——事件被 claim 后从未被 ack，烂尾在 processing，永远到不了 Agent 眼前。
- **实现要点（GPT #391 + Ziven 整理）**：
  1. 事件生命周期闭环：claim → processor → ack（成功 success / 失败 failed）
  2. watchdog：claimed 超 N 分钟没 ack → 自动释放可重投
  3. retry_count 累加，超上限进 dead_letter（不无限重试）
  4. 幂等：同一事件多实例消费不重复处理
  5. 失败路径审计：event创建失败/processor超时/claim后崩溃/chat_send失败都记状态，不黑盒
- 完成标准：完整链路 `mention → event created → claim → processor → ack → chat_send → 页面可见` 全通，10 秒为目标（体验指标）
