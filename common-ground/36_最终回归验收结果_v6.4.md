## 1. 回归中新发现并修复：ISSUE-4

### 现象

回归 C3（overwrite=true 覆盖已存在目标）时：

```
ERROR: COPY_VERIFY_FAILED - target written but size mismatched (source 45657, target 39493)
```

覆盖**实际成功了**（匿名 GET 确认 target 线上 45657B），但工具 verify 读回旧值 39493 误报失败。

### 根因

ISSUE-3（push verify 无重试）修复只覆盖了 github_push，**github_copy 的 verify 漏了同样的重试**。overwrite 后立即 GET 命中 GitHub 最终一致性窗口，读到旧 blob 大小 → 误报。34 号 C3 通过纯属没撞上窗口。

### 修复

github_copy 的 verify 增加与 push 相同的 3 次重试（间隔 300ms/600ms）：

```js
for (let attempt = 1; attempt <= 3 && !verified; attempt++) {
    try {
        const verifyResp = await fetch(...);
        if (verifyResp.ok) { targetFinalSize = vData.size || 0; verified = targetFinalSize === (srcData.size || 0) && targetFinalSize > 0; }
        else { targetFinalSize = 0; }
    } catch (e) { targetFinalSize = 0; }
    if (!verified && attempt < 3) await new Promise(r => setTimeout(r, 300 * attempt));
}
```

### 验证

修复后同场景重测：`verified: true, source_size: 45950, target_size: 45950, overwritten: true` ✅
