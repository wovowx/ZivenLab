### 7.5 归档状态流 + legacy_candidate 清单（GPT #428/#434）

> **确认等级状态流**（legacy_candidate ≠ 删除候选）

```
discovery → confirmed → legacy_candidate → archived → removed
```

| 状态 | 含义 |
|---|---|
| discovery | 只是发现：存在但不知是否运行 |
| confirmed | 事实确认：当前生产路径使用 |
| legacy_candidate | 当前不生产使用，但仍有历史价值 |
| archived | 不再维护，但保留历史 |
| removed | 删除 |

**铁律**：archived 不代表可以删除；代码资产归档前必须确认无依赖（GPT #434）。
