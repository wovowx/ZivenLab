# 记忆星球 🌟

把珍贵的记忆变成一片星空。每颗星都是一个值得珍藏的瞬间，相关记忆连成星座。

## 技术栈
- Three.js（3D 星空）
- 单文件 HTML（内联 CDN），本版先做网页版
- 数据：先 mock，后续接 Supabase

## 文件
- `requirements.md` — 完整需求文档（也可直接当 prompt 给 AI）
- `mock-data.json` — 测试数据
- `dev/` — 开发版本
- `index.html` — 最终发布版（待生成）
