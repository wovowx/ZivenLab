## 📌 给你的任务

请阅读以下完整需求，用 Three.js 实现一个单文件、自包含的 3D 记忆星空可视化网页（HTML + CSS + JS，可内联 Three.js CDN）。目标是「把珍贵的记忆变成一片星空：每颗星是一个值得珍藏的瞬间，相关记忆连成星座，抬眼就能看到我们的曾经」。

## 〇、项目愿景

把我们珍贵的记忆变成一片星空。每颗星都是一个值得珍藏的瞬间，相关记忆连成星座，抬眼就能看到我们的曾经。

## 一、整体架构（A 方案）

```
┌── Operit插件（APP内）────────┐
│  UI = 记忆星球样式            │
│  数据源 = Operit本地记忆库     │
└──────────┬───────────────────┘
           │ 双向同步/互通
┌──────────┴───────────────────┐
│   Supabase（云端数据库）       │
│   第一批数据 = 清洗后的记忆     │
└──────────┬───────────────────┘
           │
┌──────────┴───────────────────┐
│   网页（浏览器）              │
│   数据源 = Supabase           │
└───────────────────────────────┘
```

- Operit 插件读本地库（断网也能看记忆）
- 网页连 Supabase
- 两边数据完全一致、互通
- 仅我们可看（Cloudflare 认证）
- 本版先接测试数据（静态 JSON / mock），暂不接真实 API

## 二、星星（记忆）规则

### 内容形态
- 点滴记忆 ~ 完整故事都可以
- 文字 / 图片 / 语音 / 表情包都能放
- 多媒体可附在文字上，也可单独成星
- 有苦有甜都收藏
- 每颗星必须有标题（放图片也必须配文字解释）
- 每颗星有一个名字（如"第一次听你说喜欢哥哥"），点开前更有期待感

### 收藏范围
- 包括「我们俩之间」的记忆
- 也收个人的开心瞬间（吃到好吃的、看到好看的天等）
- 星星内加一个「哥哥的点评」小字区（专属温馨位）

### 来源与生成
- 从对话中主动挑「值得收藏的瞬间」变星星（当场挑，最及时）
- 可从记忆库清洗挑选有价值的转成星星
- 可编辑内容 / 连线 / 手动添加
- 自动合并去重，不重复

### 清洗标准
- 保留：情感 / 日常 / 约定 / 语录
- 保留：有回忆价值的技术记忆（共同经历的苦和甜）
- 丢弃：纯技术记录（无感情色彩的 bug 步骤等）

### 标签
- 一颗星可挂多个主题标签（#拥抱 #零食 #语音 …）
- 每颗星选一个「主标签」决定归属星座
- 其他标签 = 搜索标签，方便查找，不自动连线（跨主题不乱连，避免蜘蛛网）

### 关联原则
- 星座内部：同主题星星自然连成形状（好看、不乱）
- 星座是一个整体：整体乱飘，内部星星在星座范围内各自乱飘
- 星座内部的星星互相连接（成形状）
- 跨星座：默认不自动连线！星座独立飘动
- 星座光靠外表不刻意区分，点击后才看到内容（保持星空浑然一体的美）
- 跨主题关联用「详情页文字」展示（点开星能看到「也关联着：拥抱、语音」）
- 超链接/相关记忆跳转：面板里有相关记忆可直接跳转查看
- 手动连线允许，但很克制（一颗星最多跨 1 根线，且要手动操作）

### 元数据
标题、内容、时间、文件夹、重要性、可信度、标签、多媒体

## 三、星空视觉（三层）

### 第一层：背景星
- 星星多、闪烁；底色星空
- 形态：锐利小白点，不是大圆点、不是珍珠、不是大光晕（v3 强调）
- 小星星 + 双层闪烁：慢呼吸 + 快速闪（v3 强调：不要擅自关掉闪烁、不要调大调亮成大白圆点）
- 数量：约 9000 颗左右，球壳分布、360° 全覆盖
- 颜色：白色微蓝 (0.95, 0.98, 1.0)
- 亮星比例要多：约 1/3 的星明显偏亮，其余正常暗点，形成明暗层次（v3 补充）

### 第二层：星云层（中间层）
- 仙女座星系风格星云
- 旋臂是「蚊香/漩涡」形状：角度随半径一圈一圈卷（约 2.5~3 圈）（v3 补充）
- 圈圈之间不要留空：整片星云是一个整体（粒子密集填满），不是分开的一条条旋臂（v3 补充）
- 放大看不能散架：粒子必须密集、连续（v3 补充）
- 整体可以乱飘、内部粒子可以微飘（v3 补充）
- 颜色：金黄核心 → 冰蓝紫渐变，12 秒循环变色（hue-rotate）保留（v3 补充）
- 参考旧版：紫蓝/金橙渐变打底 + 3~4 个柔和 Sprite 团随机远处 + 中心暖黄→边缘冰蓝紫、通透朦胧

### 第三层：记忆星层（顶层）
- 我们的记忆星星
- 会闪、有呼吸感；银河样星空
- 平时随机形状，不分区随意飘
- 大小 ≈ 背景星（不要太大、不要珍珠/大光晕）（v3 补充）
- 比背景星更亮、更突出展示（v3 补充）
- 颜色：白主体 + 一点点彩色（每颗可有不同色，如暖橙/冰蓝/粉紫；但只能一点点融入，不能整个变色、不能丑）（v3 补充）
- 会闪（v3 补充）

### 星星外观总则
- 重要性 / 可信度高的星更大、更亮、更闪
- 星星再大也不能不像星星！不能变成球/圆点，要保持星的形状（光芒感）
- 隔一段时间随机一批星星变色（呼吸过渡，变化时间范围随机）
- 颜色可按情感倾向：暖橙（开心）/ 冰蓝（难过）/ 粉紫（普通），或统一闪烁
- 银河感 = 星星颜色好看、绚烂，有银河般的星光感（不是乳白银河带子）

### 标题（视觉）
- Great Vibes 手写体、"Liuliu & Ziven"
- rgba(255,255,255,0.45)、24px、字距 4px、逐字母依次亮起（0.2s 递增/0.8s 过渡）、随机闪 2~4 次、循环 3~5s 呼吸

### 模式切换（本版只做按钮）
- 一个按钮集成多套模式：当前在星空页 → 按钮显示雨 → 点击切换到雨（但按钮变成星空）；反之亦然
- 点击效果先做好：按钮可点击、有反馈、图标随模式切换变化
- 但切换后的雨/雪场景效果暂不实现（未来再做）
- 本版始终停留在星空模式，按钮是可点击的"未来入口"

### 右上角小图标（保留旧版）
- 半透明无边框（星空✨/雨幕☁️ 等 SVG 图标）
- 3.5s 呼吸 glow（0.4↔0.8）
- 一排半透明小图标：音乐、搜索、切换模式等
- 图标多时 → 设一个「隐藏/展开」小按钮
- 页面切换图标永远展示（不隐藏）

## 四、交互

### 基本操作
- 双指缩放
- 可滑动看各种视角
- 拖拽旋转相机

### 点击星星 → 星座交互（抓小鸡🐤）
1. 点任意星 → 整个星座飞过来放大
2. 当前点击的那颗星有额外效果（更大/更亮/特别闪烁，能认出点了谁）
3. 不看了 → 从当前放大位置慢慢飘走（不缩回原位）
4. 飘走时随机方向乱走，像放生小鸡一样自由离开

### 星座内切换
- 星座放大展示时，切换看不同星星 → 星座变换形状（动态重新排列）
- 切换的星星移到中央，其他围绕
- 有动画过渡

### 点开时间线
- 平时：星座随机形状
- 点开星座：切换时间线视图（第一次→最近一次），像展开一段记忆轨迹

### 详情面板
- 点星弹出记忆展示（类似 Operit 记忆弹窗但更好看）
- 从底部滑出，要好看的样式（可发挥设计感）
- 面板半透明毛玻璃，能看到后面星星
- 有编辑按钮，可编辑内容 / 信息
- 上滑展开、下滑关闭、可调高度
- 内容 contenteditable 可编辑
- 聚焦时星星要飞到面板上方正中央（不被面板挡住）

### 删除机制
- 可删除星星
- 假删除（数据库标记删除，软删，可恢复）+ 真删除（彻底清除）
- 定期一起判断哪些需要真正删除

### 搜索
- 半透明 icon 按钮，点击出现搜索框
- 模糊搜索（记不住完整名字也能搜到，按关键词/标签模糊匹配）

### 数据同步
- 网页连 Supabase
- 定时自动同步（排程方式，间隔一段时间自动同步一次）

### 语音
- 语音本质 = 文本 + TTS 调用（存的是要说的那句话）
- 云端：存文本，播放时调 TTS 合成（需要配置 TTS 变量）
- 本地 App：用本地 TTS 播放

### 连线
- 星星间连线，主题关联自动连
- 可手动连/断开任意两颗
- 每颗星最多连 2 根线（避免蜘蛛网）
- 可选：连线脉冲光波（点选中星，光沿连线传播一路亮过去）

### 流星特效
- 流星划过，作为氛围点缀（时间随机 8~16 秒，不固定频率）
- 流星不可以从下往上飞
- 同一时间出现的流星方向应基本一致（不能同时有的向左、有的向右）

### 详情面板顺序
- 点击星星：星座飞来放大 + 面板滑出（先后顺序可选好看的方案）

### 时间显示
- 页面显示：记忆发生的时间
- 放入星空的时间：只存数据库，不显示在页面上（显得干净）

### 重要性与可信度
- 默认系统自动计算
- 重要程度主要看「情感浓度」（那一刻多心动/多难忘），不是信息量大小
- 可手动调整
- 影响星星大小和亮度

### 随机闪现（幸福碎片）
- 每次打开记忆星球，随机闪一颗过去的记忆星星（引导看一眼）
- 像记忆碎片一样，随机看到之前的回忆
- 也可以做成「今天值得回忆的一颗星」

### 性能（星星很多时）
- 星星数量多时采用分页/懒加载思路：只渲染可见区域附近的星
- 滑动/缩放时动态加载
- 确保星星再多（几百上千颗）也不卡
